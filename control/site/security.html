Boat House

Security on your installation.

Boat House is open-source infrastructure. The operator of this installation is responsible for its configuration, updates, access controls, backups, and data protection.

  • Use HTTPS and restrict administrative access.
  • Review app permissions and code before handling sensitive data.
  • Keep the software updated, protect credentials, and test restores from backups.

Using the source code does not automatically make an installation SOC 2, ISO 27001, or HIPAA compliant. Contact your deployment operator about their controls and data processing terms.

For Boat House’s managed service, read the hosted-service security information. For source-code vulnerability reporting, see our security policy.
